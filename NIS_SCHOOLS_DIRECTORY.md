# NIS_SCHOOLS_DIRECTORY.md

Справочник адресов школ и организаций для тендерных поставок.

Важно: этот файл — шаблон. Не считать адрес подтверждённым, пока агент не проверит официальный сайт, 2GIS или документ тендера.

## Правило

Если в городе несколько школ/корпусов, агент не выбирает сам. Он показывает варианты пользователю и спрашивает, куда поставлять.

## Туркестан

Статус: требуется проверка при каждом тендере.

Действие агента:
1. Найти НИШ/школу в официальных источниках.
2. Проверить адрес в 2GIS.
3. Если есть несколько адресов/корпусов — спросить пользователя.

## Шымкент

Статус: требуется проверка при каждом тендере.

Действие агента:
1. Проверить, какая именно школа/организация указана в тендере.
2. Не выбирать НИШ автоматически, если школ несколько.
