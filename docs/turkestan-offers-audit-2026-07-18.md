# Туркестан — аудит предложений по двум новым заявкам

Дата исследования: 2026-07-18.

## Результат

- заявка A: 20 позиций, итог **648 820 ₸ без НДС**;
- заявка B: 25 позиций, итог **1 377 230 ₸ без НДС**;
- общий тендерный объём: **2 026 050 ₸ без НДС**;
- создано **225 предложений**: ровно по 5 на каждую из 45 позиций;
- создано 19 новых карточек поставщиков; существующая карточка `Otvertka.kz` переиспользована;
- у каждой строки заполнены relation `Заявка`, `Поставщик`, источник, статус `Нужно связаться`, уровень доказательности и готовое сообщение поставщику;
- совместимые relation `Заявки.Поставщики` синхронизированы из пяти предложений каждой строки;
- исходные наименования, техспеки, количества и тендерные цены не менялись;
- победители автоматически не выбирались.

## Доказательность цен

Публичная цена нашлась только у трёх конкретных карточек:

| Заявка / № | Источник | Публичная цена | Сравнение с лимитом |
|---|---|---:|---|
| B / 22 | ADA, Hunter PGV-201-B | 43 359 ₸ | выше лимита 42 000 ₸ |
| B / 22 | Садовый центр, Hunter PGV-201-B | 52 415 ₸ | выше лимита |
| B / 23 | ProGarden, Hunter PGJ-04 | 6 345 ₸ | ниже лимита 8 700 ₸ |

Остальные 222 записи — реальные поставщики/каталоги, но не подтверждённые коммерческие предложения. Цена, остаток, документы, доставка в Туркестан и соответствие полного ТЗ должны быть получены из ответа поставщика; пустые поля не заменялись догадками.

## Маршрут поставщиков

- Туркестан: `Insan`, `Delfin`, `Alem`, `Kuat`, `Samgau`, `NRG`;
- Казахстан / доставка: `JAKKO`, `MPS`, `BIST`, `KSK`, `LKTools`, `TopTools`, `KRASKA`, `IEK`, `Otvertka.kz`;
- полив: `Садовый центр`, `ADA`, `ProGarden`, `Водяной`, `Irrigator Kazakhstan`.

## Независимые проверки после записи

- 45/45 строк имеют ровно 5 `Предложений`;
- 45/45 строк имеют ровно 5 прямых relation `Поставщики`;
- 225/225 ключей наблюдения уникальны;
- 0 строк без заявки, поставщика, источника, сообщения или правильного рабочего статуса;
- 3 карточки с публичной ценой, 222 — без выдуманной цены.

Повторный SQL-запрос после этого аудита был отклонён лимитом бесплатного тарифа Notion connector. Успешный аудит выше выполнен до исчерпания лимита.

## Практическое использование

1. Открыть нужную строку `Заявки` и связанные `Предложения`.
2. Начать с локальных поставщиков и карточек с точным артикулом.
3. Скопировать готовое сообщение WhatsApp из предложения.
4. После ответа записать фактическую цену, наличие, НДС, документы, срок и доставку.
5. Только после подтверждения ТЗ сравнивать полную себестоимость и выбирать предложение.
