# Как собрать проект “Тендерный закупочный агент”

Версия: 2026-05-29

## 1. Что вставить в Project Instructions

Открой настройки проекта → Instructions → вставь содержимое файла:

`PROJECT_INSTRUCTIONS_SHORT.txt`

Это короткое ядро. Оно должно влезть в поле инструкций.

## 2. Что загрузить в Sources / Files проекта

Загрузи в источники проекта эти файлы:

1. `TENDER_AGENT_FULL_SOP.md` — полный регламент агента.
2. `SUPPLIER_MESSAGES.md` — шаблоны сообщений поставщикам.
3. `FINAL_TABLE_TEMPLATE.xlsx` — таблица для расчёта закупки.
4. `CITY_LOGISTICS_RULES.md` — правила выбора городов и доставки.
5. `NIS_SCHOOLS_DIRECTORY.md` — шаблон справочника школ/адресов.
6. `CHECKLIST_BEFORE_ORDER.md` — финальный аудит перед заказом.
7. `BAD_SUBSTITUTIONS.md` — опасные замены и частые ошибки.
8. `BROWSER_AGENT_WORKFLOW.md` — правила работы браузерного агента.
9. `SAVED_PROMPTS.md` — команды, которые можно сохранить как Saved Prompts.

## 3. Как запускать новый тендер

Создай новый чат внутри проекта и вставь Saved Prompt “Полный запуск тендерного пайплайна”.

Затем добавь:
- город;
- школу/организацию;
- адрес, если есть;
- номера позиций;
- разрешение искать в других городах;
- разрешение писать поставщикам;
- минимальную маржу, если есть.

## 4. Главная логика проекта

Project Instructions — короткая конституция.

Файлы проекта — подробные регламенты и шаблоны.

Saved Prompts — быстрые кнопки запуска.

Один тендер — один отдельный чат.

## 5. Критически важное правило

Товар нельзя считать найденным, пока не подтверждены:
1. соответствие ТЗ;
2. фасовка;
3. цена;
4. наличие;
5. доставка.

Дешёвый похожий товар без подтверждения — это риск, а не решение.
