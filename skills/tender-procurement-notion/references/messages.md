# Supplier Message Drafts

Use these as drafts only. Do not send unless the user explicitly approves the exact action.

## Stock, Price, And Spec

```text
Здравствуйте! Подскажите, пожалуйста, актуально ли наличие товара:

Товар: [PRODUCT]
ТЗ: [SPEC]
Фасовка/размер: [UNIT_SIZE]
Количество: [QTY]
Город/адрес доставки: [CITY_ADDRESS]

Нужно уточнить:
1. Есть ли в наличии нужное количество?
2. Цена за единицу актуальна?
3. Фасовка/размер точно такие?
4. Товар подходит под назначение из ТЗ?
5. Можете доставить сегодня/к сроку?
6. Сколько стоит доставка?
7. Можете отправить фото товара/упаковки?
8. Возможен чек/накладная/счёт?
```

## Same-Day Purchase

```text
Здравствуйте! Нужно купить сегодня:

[PRODUCT], [UNIT_SIZE], [QTY].
Лимит цены: до [PRICE_LIMIT] за единицу.
Адрес доставки: [ADDRESS].

Подтвердите, пожалуйста:
- наличие [QTY] прямо сейчас;
- финальную цену;
- доставку сегодня и время;
- фото товара;
- чек/накладную.
```

## Rebrand Or Analog Check

```text
Здравствуйте! По ТЗ нужен [OLD_NAME].
Нам сказали, что сейчас он может называться [NEW_NAME].

Нужно подтвердить:
1. Это тот же производитель/линейка или официальная замена?
2. Совпадает ли цвет/номер/фасовка: [PARAMS]?
3. Можете отправить фото товара и каталога?
4. Есть ли [QTY] в наличии сегодня?
```

## Final Confirmation Before User Orders

```text
Перед оплатой подтвердите, пожалуйста:
1. Товар: [PRODUCT]
2. Фасовка/размер: [UNIT_SIZE]
3. Количество: [QTY]
4. Цена за единицу: [UNIT_PRICE]
5. Итого за товар: [ITEM_TOTAL]
6. Доставка: [DELIVERY_PRICE]
7. Общая сумма: [TOTAL]
8. Срок доставки: [DEADLINE]
9. Документы: [RECEIPT/INVOICE]
10. Фото товара приложите, пожалуйста.
```
